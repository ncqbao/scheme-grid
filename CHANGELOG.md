# Changelog

## 0.4.0 — Desktop preview

- Added self-contained Windows x64 and combined Intel/Apple Silicon Mac app installers.
- Bundled Electron's Chromium/Node runtime, plus a private Python runtime for the Windows ChemDraw connection.
- Added native CDXML file dialogs and separate editable output.
- Added a Windows active-ChemDraw connection without requiring a system ChemScript Python runner.
- Kept XML entity, size, chemistry-preservation and source-file overwrite guards.
- Retained the corrected reaction column order so arrows remain between reactants and products.
- Marked the Mac build as untested and unnotarized, and both installers as unsigned.

The earlier native add-in and ChemScript editions are separate preview workflows. They are not the installers distributed by this desktop release.
