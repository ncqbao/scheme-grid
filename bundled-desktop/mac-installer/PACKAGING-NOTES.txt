MAC INSTALLER BUILD RECIPE (Windows preparation; Mac execution still required)

1. Use the official Electron darwin-arm64 and darwin-x64 ZIPs of the SAME pinned
   version. Verify their SHA256 against that release's SHASUMS256.txt.
2. For each architecture, preserve the complete Electron.app directory, all Unix
   executable permissions and symlinks. Name its outer directory Scheme Grid.app.
3. Place the desktop app source folder at Contents/Resources/app (or app.asar).
   Electron launches it directly with its bundled Chromium and Node runtimes.
   Do not bundle a Python interpreter for Mac file mode; it does not need one.
4. This preview rebrands ONLY the main Info.plist display/name/identifier and
   version, keeping CFBundleExecutable=Electron. All original Mach-O binaries,
   nested framework/helper files and plists, executable modes and Unix links
   remain byte-identical to the official Electron ZIPs. The official ZIPs have
   no bundle CodeResources envelopes; the ARM64 main executable has its original
   linker ad-hoc signature and the Intel main executable is unsigned.
5. Add Contents/Resources/SchemeGridInstallation.plist containing:
   <plist version="1.0"><dict><key>kind</key><string>schemegrid-desktop</string>
   <key>version</key><string>0.4.0</string></dict></plist>
6. For a production distribution, finish signing each app after ALL modifications.
   A vendor Electron Mach-O signature does not attest to the Scheme Grid bundle.
   A production distribution
   needs your Apple Developer ID identity and Apple notarization. Ad-hoc signing
   can make local Mach-O signatures structurally consistent, but does not make
   an app trusted or notarized. Do not advertise an unsigned/ad-hoc build as a
   warning-free one-click Mac installation.
7. Put each finished app in this installer's Contents/Resources/payload/:
     apple-silicon/Scheme Grid.app/
     intel/Scheme Grid.app/
   Generate SHA256SUMS.txt beside each app, paths relative to that architecture
   folder. Include every regular file after signing. Preserve symlinks as links.
8. Set Unix mode0755 on Contents/MacOS/install-scheme-grid, including its ZIP entry.
   Sign the Installer.app itself with the distribution identity, then notarize
   the distributable archive on a configured signing builder. The usual Electron
   flow uses macOS; rcodesign also supports Windows with appropriate identity
   and notary credentials. Test on a clean Mac
   account of EACH supported architecture with no Python, Node or Chrome installed.

The build_mac_installer.py script verifies official Electron checksums, rewrites
ZIP entries without extracting symlinks on Windows, bundles the app sources,
and validates all copied hashes, Mach-O equality, Unix modes, helper executable
references, and symlink chains. Use --output to choose the final ZIP path.

The provided installer copies into ~/Applications without admin privileges.
It refuses an unrelated name collision and retains a marked previous version.
It does not modify security settings, remove quarantine, install certificates,
or bypass Gatekeeper. Its code has not been executed on a Mac in this workspace.
