    A quick tip

    File mode arranges the whole imported drawing. For a smaller section, save that section as its own CDXML copy first. Review the result in ChemDraw before using it in your work.

    With the Windows connection, leave only one ChemDraw application running. A selection limits cleanup to complete selected units and their annotations; without a selection, the full drawing is arranged.
